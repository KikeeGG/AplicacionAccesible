CONOCE Y COMPRENDE

¿Qué es el deterioro cognitivo?

Conocer sus características es el primer paso para comprender las dificultades que puede experimentar una persona.

Una explicación sencilla

El deterioro cognitivo es una disminución de determinadas capacidades mentales, como la memoria, la atención, el lenguaje o el razonamiento.

Puede afectar de diferentes maneras a cada persona. Algunas presentan dificultades leves, mientras que otras necesitan más ayuda para realizar actividades cotidianas.

¿Qué capacidades pueden verse afectadas?

Memoria

Dificultad para recordar nombres, fechas o acontecimientos recientes.

Atención

Problemas para concentrarse o mantener la atención.

Lenguaje

Dificultad para encontrar palabras o comprender algunos mensajes.

Orientación

Problemas para reconocer lugares, fechas o situaciones.

Razonamiento

Dificultad para resolver problemas o tomar decisiones.

Planificación

Problemas para organizar tareas y seguir instrucciones.

¿Es lo mismo que olvidar algo?

No. Tener olvidos ocasionales puede ser algo normal. El deterioro cognitivo implica cambios en determinadas capacidades mentales que pueden afectar a la vida diaria.

Si existen dificultades frecuentes de memoria o de otras capacidades cognitivas, es recomendable consultar con un profesional sanitario.
